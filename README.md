# Context-dependent memes interpretation and model limitations

This repository contains materials, notes, and experiments for this research project on meme interpretation and limitations of automated systems.

## Research Focus

This project investigates how context-dependent meanings in memes create challenges for automated models, particularly in content moderation tasks.

Key questions:
- Do models correctly identify harmful content in memes?
- When models fail, why do they fail?
- Do dataset labels reflect a true “ground truth”?
